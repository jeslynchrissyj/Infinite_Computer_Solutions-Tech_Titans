# 🎥 Project Demo Video

The interactive walkthrough and demonstration of the **RAG Chat API** project has been recorded and is hosted on GitHub Pages.

### 🌐 Demo Video Link
👉 **[GitHub Pages Demo Video](https://jeslynchrissyj.github.io/RAG-Chat-App-demo-video-/)**

---

### What is covered in the video:
1. **Introduction & Architecture**: Overview of RAG (Retrieval-Augmented Generation) and ASP.NET Core 8 Minimal APIs.
2. **GitHub Walkthrough**: Brief overview of the repository folders and CI/CD setup.
3. **Source Code deep dive**: Ingestion, semantic text chunking, in-memory vector storage, and cosine similarity.
4. **Testing**: Live execution of the 9 xUnit automated tests.
5. **Dynamic Document Upload & DB Inspect**: Using the new `/documents` endpoint to upload new data and track chunk parameters.
6. **RAG Chat Demonstration**: Asking questions and tracking search similarity scores in real-time.
